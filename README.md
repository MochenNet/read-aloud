# 乐读 (rn-read-aloud)

**在喧嚣的世界里，找到片刻的宁静。**

“乐读”是一款为你打造的沉浸式阅读与聆听应用。我们相信，文字的力量与声音的温度相结合，能为你带来独一无二的放松体验。无论是在通勤路上，还是在静谧的午后，“乐读”都将是你灵魂的栖息地。

打开“乐读”，开启你的静心之旅。

## ✨ 核心功能

*   🎵 **沉浸式体验**: 我们精心挑选了舒缓的背景音乐，并为您提供高质量的文章朗读。闭上眼睛，让声音带你进入文字的世界。
*   📖 **每日精选**: 每天一篇文章，不多不少。我们相信，深度阅读比碎片化浏览更有价值。
*   🌙 **深色模式**: 无论白天黑夜，切换你喜欢的主题，享受最舒适的阅读界面。
*   ❤️ **收藏所爱**: 遇到触动你的文字？一键收藏，随时回顾。

## 💻 技术栈

*   **框架**: React Native & Expo
*   **语言**: TypeScript
*   **导航**: React Navigation
*   **样式**: Styled Components
*   **音频**: expo-av

## 打包

```
eas build -p android --profile preview
```

## 如何运行

1.  **克隆仓库**:
    ```bash
    git clone 
    ```
2.  **进入目录**:
    ```bash
    cd rn-read-aloud
    ```
3.  **安装依赖**:
    ```bash
    npm install
    ```
4.  **启动应用**:
    ```bash
    npm run dev
    ```
