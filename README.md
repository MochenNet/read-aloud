# 阅声 (rn-read-aloud)

这是一个使用 React Native 和 Expo 构建的移动应用，旨在提供一个沉浸式的阅读和聆听体验。

## 主要功能

*   **每日文章**: 每天为用户推荐一篇精选文章。
*   **文章朗读**: 提供文章的音频版本，让用户可以随时随地聆听。
*   **随机音乐**: 内置随机音乐播放器，为阅读增添背景音乐。
*   **主题切换**: 支持浅色和深色两种主题模式。
*   **个性化**: 用户可以收藏喜欢的文章，并查看历史记录。

## 技术栈

*   **框架**: React Native with Expo
*   **语言**: TypeScript
*   **导航**: React Navigation
*   **样式**: Styled Components
*   **音频**: expo-av

## 如何运行

1.  克隆仓库:
    ```bash
    git clone 
    ```
2.  进入项目目录:
    ```bash
    cd rn-read-aloud
    ```
3.  安装依赖:
    ```bash
    npm install
    ```
4.  启动应用:
    ```bash
    npm run dev
    ```
