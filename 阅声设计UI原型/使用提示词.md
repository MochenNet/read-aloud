## 1. 技术栈

本项目是一个基于 React Native 和 Expo 构建的移动应用。

*   **核心框架**:
    *   `react`: 19.0.0
    *   `react-native`: 0.79.5
    *   `expo`: 53.0.22
*   **编程语言**:
    *   `typescript`: ~5.8.3
*   **路由/导航**:
    *   `@react-navigation/native`
    *   `@react-navigation/bottom-tabs`
    *   `@react-navigation/stack`
*   **UI/样式**:
    *   `styled-components`: 核心样式方案。
    *   `expo-linear-gradient`: 用于创建渐变背景。
    *   `react-native-vector-icons`: 图标库。
    *   `react-native-safe-area-context`: 处理安全区域。
*   **原生功能/模块**:
    *   `expo-av`: 音频播放。
    *   `@react-native-async-storage/async-storage`: 本地持久化存储。

## 3. 核心架构

### 3.1. 应用入口与全局上下文

*   **入口**: `App.tsx` 是应用的根组件。
*   **全局提供者 (Providers)**: 应用顶层由多个全局 Context Provider 包裹，顺序如下：
    1.  `SafeAreaProvider`: 处理屏幕安全区域。
    2.  `ThemeProvider`: 管理全局主题（浅色/深色模式）。
    3.  `UserDataProvider`: 管理用户数据（收藏、历史）。
    4.  `NavigationContainer`: 包含所有导航栈。
    5.  `AudioProvider`: 在导航容器内，管理全局音频播放状态。

### 3.2. 导航结构

*   **结构**: 应用采用“底部标签 (Bottom Tab) + 栈 (Stack)”的混合导航模式。
    *   **主导航**: `BottomTabNavigator` 包含“首页”和“我的”两个主标签页。
    *   **子导航**: 每个标签页内部使用 `StackNavigator` 管理页面跳转，例如从“首页”列表到“阅读”详情页。
*   **文件**: 所有导航逻辑和配置均位于 `src/navigation/index.tsx`。

### 3.3. 全局状态管理

项目通过 React Context 和自定义钩子进行全局状态管理：

*   **主题 (`ThemeContext`)**: 通过 `useTheme()` 钩子访问，提供 `isDarkMode`, `toggleTheme`, `colors`。
*   **音频 (`AudioContext`)**: 通过 `useAudio()` 钩子访问，提供 `isPlaying`, `currentTrack`, `play`, `pause`, `stop` 等。
*   **用户数据 (`UserDataContext`)**: 通过 `useUserData()` 钩子访问，提供 `favorites`, `history` 及相关操作方法。

## 4. 关键模式与实践

### 4.1. 类型安全的主题系统

*   **核心**: 项目实现了完全类型安全的 `styled-components` 主题。
*   **机制**: 通过 `src/styled.d.ts` 文件扩展 `DefaultTheme` 接口，使其与 `ThemeContext` 中定义的 `AppTheme` 类型保持一致。
*   **实践**: 在 `styled` 组件中，可以直接从 `props.theme` 中解构颜色和样式值，并获得完整的 TypeScript 类型提示和安全检查。

### 4.2. 导航感知的全局音频

*   **目标**: 实现音频在跨页面时持续播放，但在离开特定页面时自动停止。
*   **实现**:
    1.  `AudioProvider` 被置于导航结构的高层，以维持全局状态。
    2.  `NavigationAwareAudio` 组件使用 `useIsFocused` 钩子监听屏幕焦点。当包含音乐播放器的屏幕失去焦点时，会自动调用 `stop()` 方法。
*   **注意**: 任何需要背景音频的修改都应遵循此模式。

### 4.3. 透明渐变 UI

*   **风格**: 应用大量使用透明和渐变效果，特别是导航栏和底部标签栏，使其浮动在内容之上。
*   **实现**: 通过 `react-navigation` 的 `headerBackground` 和 `tabBarBackground` 渲染 `expo-linear-gradient` 组件，并将 `backgroundColor` 设置为 `transparent`。
